# 2.4.1 · 行情第四态（已收盘 / 休市）与交易时段建模

## 1. 问题

2.4.0 只有三态：`实时 / 延迟 / 本地快照`。所有「不在交易时段」的市场都被归为
`延迟`，日经 225 在文化の日显示 `14:30 · 21 小时前 · 延迟`，用户会以为数据坏了。
根因不是取数（东财 `f124` 与分钟 K 都停在 11-02 14:30，是真实收盘），
而是**缺少交易时段/假日模型**：无法区分「收盘价」与「源陈旧」。

## 2. 状态定义（四种 + 本地快照）

| 状态 | 判定 | 文案示例 |
|---|---|---|
| `realtime` 实时 | 市场处于交易时段，源时间 ≤5 分钟 | `12:22 · 实时` |
| `delayed` 延迟 | 市场**本应交易**却拿不到新价；或没有源时间 | `延迟（无源时间）` |
| `closed` 已收盘 | 不在交易时段，源时间 ≥ 最近一次收盘 | `已收盘 · 11-03 01:00` |
| `holiday` 休市 | 交易所假日表中该日休市，源时间 ≥ 最近一次收盘 | `休市 · 11-02 14:30` |
| `local` 本地快照 | 直连全失败，回落 `data/quotes.json` | `本地快照` |

- 午休（港股 12:00–13:00、A股 11:30–13:00、日股 11:30–12:30）显示 `午间休市 · HH:MM`，状态仍归 `closed`。
- **超过 2 分钟容差**未达到最近收盘（例如上一交易日收盘后源时间没动）才回落 `delayed`。
- 阈值仍为 `REALTIME_MAX_AGE_MS = 5 分钟`。

## 3. 交易时段（IANA 时区，不写死 +08:00）

| 市场 | IANA | 时段（当地） |
|---|---|---|
| CN / ETF | Asia/Shanghai | 09:30–11:30 / 13:00–15:00 |
| HK | Asia/Hong_Kong | 09:30–12:00 / 13:00–16:00 |
| JP | Asia/Tokyo | 09:00–11:30 / 12:30–15:30 |
| KR | Asia/Seoul | 09:00–15:30 |
| US | America/New_York | 09:30–16:00 |
| EU（德/法） | Europe/Berlin | 09:00–17:30 |
| UK | Europe/London | 08:00–16:30 |

- 一律用 `Intl.DateTimeFormat` 的 `timeZone` 转换；UTC 毫秒 ↔ 当地墙钟用两遍偏移修正（处理 DST）。
- DST 测试：美东 2026-03-06（EST）22:00 北京 = 09:00 ET 未开盘；
  2026-03-10（EDT）22:00 北京 = 10:00 ET 开盘；
  2026-10-30（EDT）开盘、2026-11-03（EST）未开盘。

## 4. 假日表 `assets/market-calendar.json`

结构：

```
{ v, updatedAt, coverage:{from,to}, sources:{JP,US}, markets:{JP:[...],US:[...],...},
  gaps:{CN,HK,KR,EU,UK} }
```

- 已核实并录入：**JPX 2026+2027**（来源 JPX Market Holidays）、**NYSE 2026+2027**（来源 NYSE Holidays & Trading Hours）。
- 其余市场（CN/HK/KR/EU/UK）暂为空数组，在 `gaps` 中如实说明「未从官方页面核实」；
  这些市场只按交易时段显示 `已收盘`，**不会猜休市**。
- **过期降级**：日期超出 `coverage.from~to` 时 `holidaySet` 返回空集合，
  按交易时段判断（最多显示 `已收盘`），绝不标 `休市` 或 `实时`。
- 维护：每年 12 月更新一次（下一年的官方日历通常已发布）；更新 `coverage.to`、
  `markets`、`sources`、`updatedAt`。测试锁定 `coverage.to >= 2027-12-31`，防止悄悄过期。

## 5. 全局标题

不再取跨市场最旧时间：

- 有实时市场：`部分市场已收盘 · 最新 12:22`（state 仍为 realtime，绿色）；
- 全部收盘/休市：`全市场已收盘 · 最近收盘 01:00` / `休市 · 最近收盘 14:30`；
- 全部延迟：沿用 2.4.0 的「最旧源时间」口径；
- 卡片、标题、页脚共用同一 `aggregateStatus` / `quoteStatus` 结果。

分组标题「交易中/休市」也改用同一 `sessionAt`，避免「日本 交易中」与卡片「休市」冲突。

## 6. 测试

`tests/market-session.test.mjs`（12 项）：日本休市、正常开盘、港股午休、
德法英美收盘、A股开盘/午休、DST 两段边界、假日表过期降级、覆盖期下限、
全局三种聚合、无市场信息的旧口径回归。
