# 实时 K 线 · 站内阅读 · 国内视角 设计规范

日期：2026-10-05
状态：已确认，进入实现

## 背景与目标

「宏观资讯台」是纯静态站（GitHub Pages，无服务端）。本次要做三件事：

1. **K 线图实时展示**：当前分钟级 / 周月级 K 线依赖 Cloudflare Worker，
   而 `workers.dev` 在国内被 DNS 污染，实际只有本地日 K 快照可用。
2. **站内阅读新闻**：当前点击条目跳到源站，希望在站内读完。
3. **国内视角**：目前偏大宗与全球宏观，需补 A 股 / 国内财经 / 政策监管来源。

同时修复已发现的 bug。

## 关键技术结论（实测）

东财 `push2`（行情）与 `push2his`（K 线）返回 `Access-Control-Allow-Origin: *`，
腾讯 `qt.gtimg.cn` / `web.ifzq.gtimg.cn` 同样返回 `*`。
**浏览器可直连，且国内可达**，因此被封锁的 Worker 不再是必要依赖。

东财 `push2his` 对全部 17 个指数（含此前认为缺失的恒生科技 / 日经 225 /
德国 DAX / 英国富时 100 / 韩国 KOSPI）均有历史数据，支持
1/5/15/30/60 分钟与日/周/月。

## 方案

### A. 实时行情 + K 线（浏览器直连东财）

新增 `assets/market.js`（零依赖）：

- 指数映射 `key → secid`，与 `src/sources.mjs` 的 `INDICES` 一致
- `fetchQuotes()`：`push2.eastmoney.com/api/qt/stock/get`，并发取全部指数；
  单项失败跳过，整体失败回退 `data/quotes.json`
- `fetchKline(secid, klt, limit)`：`push2his.eastmoney.com/api/qt/stock/kline/get`，
  解析 `klines`（`日期,开,收,高,低,量,额`）为 `{t,o,h,l,c,v}`；
  失败回退本地 `data/kline/<key>.json`（仅日 K）
- `klt` 映射：`1/5/15/30/60` 分钟；`101/102/103` 日/周/月
- AbortController 8s 超时 + 内存缓存

改造 `assets/app.js`：

- 行情仪表盘改为直连实时报价（回退本地快照）；仅在**交易时段**按
  `POLL_SECONDS` 轮询
- K 线弹窗周期扩展为 分时/1分/5分/15分/30分/60分/日/周/月；
  打开且处于交易时段时自动刷新最新一根，并保持右侧缩放位置
- 修复指数卡片点击跳页首、`isTrading` 跨零点误判

### B. 站内阅读新闻

- 采集端条目新增 `content`（完整正文，上限 4000 字）：
  - 华尔街见闻：`content = content_text` 全文；`title` 用标题或正文首句截断；
    `summary` 短摘要
  - RSS：`content = description/content` 全文，`summary` 前 ~140 字
- `search.json` 仍只保留精简字段以控制体积
- 前端条目点击打开站内「阅读器」面板：来源/时间/频道/标题/正文（保留段落）
  + 「阅读原文」外链；支持上一条/下一条、Esc 关闭、移动端全屏

### C. 国内视角

- 财经新闻：东方财富 `np-listapi`、新浪财经滚动 RSS、中新网财经 RSS
- 官方政策/监管：逐个实测后接入（取不到或不被 Actions 可达的剔除）
- RSS 解析增加 charset 识别（gb2312/gbk → UTF-8）
- 频道体系补「国内/A股」；行情仪表盘 A 股分组置顶

## 实现补充（2026-10-05）

实测发现东财的行情/K 线镜像主机**会间歇性不可达**（同一时刻有的通、有的断，
报 `net::ERR_EMPTY_RESPONSE`），单个主机不可靠。据此在实现中增加了回退链：

- 行情：东财批量接口（多主机，缓存优先 + 失败并发赛其余）→ 腾讯 `qt.gtimg.cn` 批量
- K 线：东财（全 17 指数、含分钟）→ 腾讯 `web.ifzq.gtimg.cn`（日/周/月，CN/HK/US）
  → 腾讯 `minute/query`（分钟周期，用当日分时聚合，仅当天）→ 本地预生成日 K

腾讯接口返回 GBK 文本，浏览器按 UTF-8 解码会乱码，因此指数名称使用本地 `META.name`，
只从腾讯响应中取数字字段。

浏览器实测（东财整体不可达的极端情况下）：行情、日/周/月 K、1分/5分 K、站内阅读
均正常，无 JS 异常。
